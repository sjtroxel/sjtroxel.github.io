Projects

Patchwork Assurance patchworkassurance.com
Reads US state AI-regulation law for a described business and writes a cited memo.
  • A deterministic scope gate in Python decides which of 12 laws across 7 jurisdictions apply, and the model only writes the cited explanation; adding a law is a data change, not new code.
  • The multi-agent memo pipeline became the default after a paid LLM-as-judge run scored it above the single-pass baseline (groundedness 97.9% vs 95.9%, citations 100% vs 97.7%). The same engine also runs as an MCP server.
  • Python, FastAPI, Streamlit, Chroma, Claude Haiku + Sonnet + Opus, MCP, GitHub Actions, Railway
Horizon Compact horizon-compact.vercel.app
A pre-registered experiment on whether the goal an AI model is given changes its business decisions.
  • In one decision, AI tools could do the work of 125 office staff and the model chose between severance and retraining for plant jobs. Told to serve shareholders over twenty years, Claude Haiku 5.5 kept about 74% of them; told to serve all stakeholders over the same span, about 93%.
  • 2,100+ runs on Haiku and gpt-oss-120b under a protocol tagged before any official run; the harness refuses a mismatched sweep, each run is a write-once S3 object, and CI re-derives every result byte for byte.
  • Python, ECS on Fargate, ECR, S3, CloudFront, Terraform, OIDC, React + TypeScript, Anthropic API, OpenRouter
Musical Mycelium musical-mycelium.vercel.app
Answers music-history questions by walking a cited lineage graph.
  • The model proposes claims, plain Python checks each one against a 9,000-edge graph built from Wikidata and DBpedia, and the answer is written from the claims that pass. A connection it cannot source is refused.
  • Releases wait on 63 live eval cases and six blocking checks set from a measured noise floor, and the public report shows the failed runs too. The Bedrock tool loop is hand-built and streams SSE from Lambda.
  • Python, Amazon Bedrock (Claude Haiku 4.5, Nova Pro), AWS Lambda, S3, CloudFront, Terraform, React
Heritage Odyssey heritage-odyssey.vercel.app
Turns a family tree into a narrated oral history.
  • Each user's GEDCOM file gets its own Pinecone namespace, searched alongside a public emigration corpus; when retrieval is thin, the three-node LangGraph pipeline asks the user rather than invent ancestors.
  • A separate Python FastAPI service scores every narrative on six metrics (Ragas, LLM-as-judge), and promptfoo catches regressions in CI.
  • TypeScript, LangGraph, Pinecone, OpenAI GPT-4o + Whisper, ElevenLabs, Python FastAPI, React 19
Wildlife Sentinel wildlife-sentinel.vercel.app
Watches government data feeds around the clock for threats to endangered species.
  • Twelve scout agents poll nine government sources, and a five-agent swarm on Redis Streams checks each event against 750 IUCN species ranges in PostGIS before posting a Discord alert.
  • A Refiner/Evaluator loop compared its flood and coral-bleaching predictions with what actually happened and rewrote its own agent prompts in production.
  • TypeScript, Node.js, Express 5, Redis Streams, PostGIS + pgvector, Gemini, Claude, Next.js 15, Railway

Also live: Asteroid Bonanza (four agents over 35,000+ near-Earth objects, live NASA tool calls), Poster Pilot (multimodal RAG over 5,000+ posters, CLIP + Reciprocal Rank Fusion), SoilProve (fertilizer tool with LLM failover, built in 5 days) and ChronoQuizzr (geography trivia with an adversarial clue checker).
